# Test Suite — Conformance Checks

## What it is

Every binding rule in Mybizz's global ADRs, specifications, policies and security documents, with the tests in [[[default:test-suite/ts-catalogue]]](C:/dev/project-library-global/test-suite/ts-catalogue.md) that prove an application obeys it. A rule is obeyed only when its tests pass. Where a rule has been found contradictory or out of date, its test follows the fix in [[[default:test-suite/ts-rule-soundness-register]]](C:/dev/project-library-global/test-suite/ts-rule-soundness-register.md). Each application adds its own rules in the same form at Step 15 (DC-08).
