# Test Suite — Rule Soundness Register

## What it is

The rules Mybizz tests against must be sound. These are the rules found contradictory, out of date or unsafe when the test suite was built. Each entry gives what was found and the fix: the tests apply the fix now, and the source document is corrected with the developer's approval. Once a source is corrected, its entry is deleted.
